# RESCENE — SACRED TIMELINE

### ▶ **https://daforce1984.github.io/rescene-timeline/**

리센느(RESCENE)의 데뷔 이전 영상부터 2026년 역주행까지를
우주에 떠 있는 오렌지빛 타임라인으로 그린 Three.js 시각화.
사건마다 갈래가 뻗어 나오고, **2026년 3월 20일에 시간선 자체가 두 갈래로 갈라진다.**

`▶ 재생` 을 누르면 데뷔부터 오늘까지 시간선이 자라나고,
그때 지나온 뮤직비디오가 배경음으로 깔린다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `Space` · `▶ 재생` | 시간선이 자라나는 연출 |
| 휠 · 가운데 버튼 드래그 | 확대·축소 · 이동 |
| 노드 · 라벨 클릭 | 사건 상세 |
| MV 스크린 클릭 | 뮤직비디오 재생 |
| `M` / `P` | MV 갤러리 / 멤버 소개 |
| `C` / `B` | 조작 안내 / 범례 여닫기 (기본은 접혀 있다) |
| `←` `→` · `Esc` · `0` | 이전·다음 사건 · 닫기 · 초기화 |

주소 뒤에 `?era=2026`, `?e=geoje-nexus`, `?intro=0` 을 붙이면 그 지점에서 시작한다.

### 배경음 · 광고

배경음은 공식 MV 를 유튜브로 그대로 튼다. 기본은 **「LOVE ATTACK」 한 곡**이다 —
유튜브 광고는 새 재생을 시작할 때 붙으므로, 곡을 안 바꾸면 광고도 처음 한 번뿐이다.

플레이어의 **`한 곡` / `시간선`** 단추를 누르면 진행선이 마지막으로 지나온 MV 를 따라간다
(2024년엔 「LOVE ATTACK」, 거제 야호를 지나면 「Runaway」). 대신 곡이 바뀔 때마다 광고가 붙을 수 있다.
`?bgm=one` · `?bgm=line` 으로도 정할 수 있고, 고른 값은 기억된다.
광고 자체를 끄는 건 유튜브와 채널 사이의 문제라 이쪽에서 손댈 수 없다.

## 로컬에서 열기

ES 모듈을 쓰므로 `file://` 로는 안 열린다. 정적 서버가 필요하다.

```bash
python3 -m http.server 8123   # → http://localhost:8123
```

three.js · 서체 · 썸네일 · 배경음을 전부 바깥에서 받아 오므로 인터넷 연결이 필요하다.

## 구조

```
index.html       HUD 마크업 + importmap
css/style.css    HUD · 라벨 · 패널 · 카드
js/data.js       사건 · 뮤직비디오 · 멤버 · 시간축 — 내용은 전부 여기
js/main.js       Three.js 씬 전체
tools/check.mjs  브라우저 없이 돌리는 검사기
```

사건을 더하거나 고치려면 `js/data.js` 의 `EVENTS` 배열만 손대면 된다.
날짜만 적으면 좌표는 알아서 잡힌다.

코드를 고쳤으면 이걸 먼저 돌릴 것:

```bash
node tools/check.mjs
```

실제 three.js 로 씬을 다 만들고, 라벨과 버튼을 전부 눌러 보고,
재생을 끝까지 돌린 뒤 결과를 숫자로 찍어 준다.

## 저장소에 없는 것

- **음원 파일** — 배경음은 공식 MV 를 유튜브로 그대로 튼다

멤버 사진(`assets/members/`)은 들어 있다. 파일이 없으면 그 멤버의 **데뷔 트레일러
유튜브 프레임**으로 대체되고, 그것도 안 되면 이름 첫 글자 동그라미가 자리를 채운다.
